# Documentação do sistema (fonte local)

Esta pasta é a **fonte da verdade** da GitHub Wiki do sclinic — handbook para colaboradores (produto + engenharia).

## Publicar

```bash
npm run docs:wiki:sync
```

Requisitos: Wiki habilitada no GitHub + primeira página criada + SSH (`git@github.com:ViniciusSantos31/sclinic.wiki.git`).
