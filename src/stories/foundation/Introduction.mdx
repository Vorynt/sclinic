# Foundation

Bem-vindo à documentação de foundation do **sclinic Design System**.

O DS combina **shadcn/ui** (estilo Radix Nova) com **Tailwind CSS v4**. Tokens visuais vivem em `src/app/globals.css` (variáveis CSS em oklch) e são documentados em `src/config/theme.ts`.

## Dark mode

Use a toolbar **Theme** no topo do Storybook para alternar entre **light** e **dark**. O addon aplica a classe `dark` no elemento `<html>`, espelhando o comportamento da aplicação.

## Tokens

Explore os blocos de foundation:

- **[Colors](./?path=/docs/foundation-colors--docs)** — tokens semânticos, chart e sidebar
- **[Typography](./?path=/docs/foundation-typography--docs)** — famílias, tamanhos e pesos
- **[Radius](./?path=/docs/foundation-radius--docs)** — escala de border-radius
- **[Spacing](./?path=/docs/foundation-spacing--docs)** — escala de espaçamento Tailwind

## Uso na aplicação

- Prefira classes utilitárias (`bg-primary`, `text-muted-foreground`, `rounded-lg`, `p-4`) em vez de valores hardcoded.
- Cores e radius reagem ao tema via CSS variables — teste sempre em light e dark mode.
- Tipografia: `font-sans` (corpo), `font-heading` (títulos), `font-mono` (código).
